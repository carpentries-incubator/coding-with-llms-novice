# AI Carpentry: Learning to Code with AI Chatbots
An introduction to programming with a GenAI chatbot as a learning assistant, for novice programmers working in research.
Part of AI Carpentry's [Learning Programming with GenAI](https://carpentries-incubator.github.io/ai-carpentry-user-workshop-novice/) workshop.

This lesson is in the early stages of development.
